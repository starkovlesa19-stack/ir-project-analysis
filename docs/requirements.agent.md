# Требования

## Функциональные требования

| ID | Требование | Источник | Приоритет |
|---|---|---|---|
| FR-01 | Система должна регистрировать пользователей с ролями | HR | Must |
| FR-02 | Система должна аутентифицировать по email и паролю | HR | Must |
| FR-03 | Система должна добавлять сотрудника с ФИО, должностью, подразделением | HR | Must |
| FR-04 | Система должна редактировать данные сотрудника | HR | Must |
| FR-05 | Система должна оформлять увольнение с датой | HR | Must |
| FR-06 | Система должна переводить сотрудника в другое подразделение | HR | Must |
| FR-07 | Система должна вести табель учёта рабочего времени | HR | Must |
| FR-08 | Система должна оформлять отпуск с согласованием | HR | Should |
| FR-09 | Система должна формировать отчёт по кадрам | Руководитель | Should |
| FR-10 | Система должна искать сотрудников по ФИО | HR | Should |
| FR-11 | Система должна фильтровать табель по дате и подразделению | HR | Should |
| FR-12 | Система должна отправлять уведомления о согласовании | Сотрудник | Could |

## Проверка качества
– Полнота: все роли покрыты
– Непротиворечивость: FR-01 vs FR-08 — уточнено
– Выполнимость: FR-12 отложено
