# Глоссарий

## 3. Глоссарий
| Термин | Определение|
|--------|------------|
| Сотрудник | физическое лицо, состоящее в трудовых отношениях с предприятием |
| Штатное расписание | документ, определяющий структуру, штатный состав и численность организации|
 Приказ — распорядительный документ по личному составу. Личная карточка (Т-2) — основной документ учёта персональных данных сотрудника. Трудовой договор — соглашение между работником и работодателем. Кадровый резерв — группа сотрудников, потенциально готовых к занятию руководящих должностей.
