1. Описание ПРО

Информационный ресурс «Кадровый учёт предприятия» — это система управления персоналом, предназначенная для автоматизации учёта сотрудников, ведения кадрового делопроизводства, расчёта стажа и формирования отчётности. Система позволяет централизованно хранить данные о сотрудниках, отслеживать их перемещения, отпуска и больничные, а также автоматизировать формирование приказов и отчётов для контролирующих органов.

2. Границы ПРО

Входит: учёт личных данных сотрудников; ведение штатного расписания; учёт приёма, перевода и увольнения; учёт отпусков и больничных; формирование кадровых приказов; ведение воинского учёта; формирование отчётности (П-4, Т-1, Т-2). Не входит: бухгалтерский и налоговый учёт; расчёт заработной платы (начисление); управление производственными задачами; управление доступом на территорию (СКУД); медицинское страхование и льготы; психофизиологическое тестирование; обучение и развитие персонала (кроме фиксации факта).

4. Бизнес-процессы «AS IS» (Как есть)

Процесс 1: Приём на работу. Участники: кандидат, HR-менеджер, руководитель отдела, директор. Шаги: сбор документов → собеседование → принятие решения → подписание трудового договора → создание приказа о приёме → внесение данных в журнал/Excel. Проблемы: бумажная волокита, потеря документов, долгое согласование приказов, дублирование данных в разных таблицах.

Процесс 2: Учёт отпусков и больничных. Участники: сотрудник, HR-менеджер, бухгалтер. Шаги: написание заявления → проверка графика отпусков → согласование с руководителем → издание приказа → отметка в табеле учёта рабочего времени. Проблемы: человеческий фактор (ошибки в подсчёте дней), сложность отслеживания остатков отпусков, задержки в передаче данных в бухгалтерию.

Процесс 3: Формирование отчётности. Участники: HR-менеджер, бухгалтер, статистические органы. Шаги: сбор данных из журналов → ручной подсчёт показателей → заполнение форм (Т-1, Т-2, П-4) → отправка отчётов. Проблемы: высокая трудоёмкость, риск ошибок при ручном переносе, необходимость сверки данных с бухгалтерией.

Процесс 4: Увольнение сотрудника. Участники: сотрудник, HR-менеджер, руководитель, бухгалтерия. Шаги: заявление на увольнение → отработка (2 недели) → издание приказа → расчёт компенсаций → выдача трудовой книжки. Проблемы: задержки в оформлении, необходимость проверки наличия задолженностей (обходной лист), долгое закрытие доступа к ресурсам.

5. Анализ аналогов

1С: Зарплата и управление персоналом. Сильные стороны: мощный функционал, интеграция с 1С:Бухгалтерия, соответствие законодательству. Слабые стороны: высокая стоимость, сложность настройки, требует специалистов. SAP HCM. Сильные стороны: масштабируемость, поддержка международных стандартов. Слабые стороны: очень дорого, сложно для малого и среднего бизнеса, долгое внедрение. БОСС-Кадровик. Сильные стороны: гибкость, наличие отечественных разработок. Слабые стороны: устаревший интерфейс, сложность интеграции со сторонними сервисами. Excel / Google Таблицы. Сильные стороны: бесплатно, простота использования. Слабые стороны: отсутствие автоматизации, риск ошибок, нет разграничения прав доступа, нет истории изменений.
