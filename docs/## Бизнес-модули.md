## Бизнес-модули

| Модуль | Назначение | Взаимодействует с |
|---|---|---|
| Auth | Аутентификация, роли | Users |
| Employees | Управление сотрудниками | Departments, Positions |
| Departments | Управление подразделениями | Employees |
| Timesheet | Учёт рабочего времени | Employees, Reports |
| Leaves | Отпуска | Employees, Notifications |
| Reports | Отчёты | Employees, Timesheet |
